# SMTX Demo Builder 使用指南

SMTX Demo Builder 是面向 Windows 上 Microsoft Edge / Google Chrome 的本地互动演示工具。它把网页操作录制为演示，在录制的点击操作上设置交互热点，再让观看者按预设顺序点击热点继续播放。回放画面不会在原 Web 平台执行操作。

本指南面向使用工具录制和播放演示的同事。首次安装扩展、校验安装包和更新版本，请参阅[内测试点指南](../pilot/README.md)。

## 开始前

- 准备可正常访问的 HTTP 或 HTTPS 演示网站。内网站点通常需要先连接 VPN；浏览器内部页面不能录制。
- 使用经批准的测试数据。录制文件可能保存页面文字、图片和字体；输入框的值默认会被遮蔽，但页面上的普通文本仍可能进入快照。不要录入客户真实数据、密码或访问令牌。
- 在电脑上选择一个固定的本地目录作为**演示素材库**。它与扩展安装目录不同；工具生成的演示保存在这里，不会自动上传到服务器。避免使用临时目录或自动同步网盘。
- 一次录制针对一个浏览器标签页的主文档。录制期间保持 SMTX Demo Builder 侧边栏打开。

## 第一次录制：从网页到互动演示

1. 点击浏览器工具栏中的 **SMTX Demo Builder**，打开侧边栏。在“本地素材库”区域点击“选择素材库目录”，选中本机目录并授予访问权限。再次使用时如出现权限提示，点击“授权并刷新素材库”。
2. 在“录制演示”区域填写完整的“目标页面地址”，点击“打开目标页面”。先确认新标签页已正常加载、可以操作，再填写“演示名称”。也可以先打开目标网页，然后返回侧边栏开始录制；若提示“请先打开要录制的页面”，优先使用“打开目标页面”按钮重新指定目标标签页。
3. 点击“开始录制”，按浏览器提示授予目标网站的访问权限。看到“录制进行中”后，在目标页面执行要展示的操作路径。尽量只保留演示需要的步骤；录制期间保持侧边栏打开。同一标签页刷新后会重新启动录制，但不会把另一个标签页的操作并入当前演示。
4. 完成操作后，返回侧边栏点击“结束录制并保存”。保存完成会打开热点编辑器；同时，新演示会出现在“我的演示”中。若提示仅保存了部分录制数据，应检查演示末尾是否完整，再决定是否重录。
5. 在热点编辑器右侧的“点击操作”列表中，选择需要观看者参与的一次点击。预览会定位到该操作之前。确认“热点名称”后点击“添加交互热点”；按需要重复此操作。右侧“交互步骤”列出已保存的热点，可用“移除”删除某一步。
6. 点击“播放演示”。播放器到达交互步骤时会暂停并提示“请点击：…”。观看者点击画面中的高亮区域后继续；点击其他位置只会显示提示，不会跳到下一步。建议从头播放一次，检查每个热点的位置、名称和顺序。

## 播放器控制

- “从头播放”将演示返回起点；“全屏”扩大播放区域。带热点的演示按热点顺序引导；没有热点的演示为自由回放。
- “播放加速”默认“关闭”，按录制原速播放。选择 1 秒、2 秒或 3 秒后，超过该时长的相邻点击间隔会约按所选时长播放，较短间隔保持原速。鼠标轨迹和页面变化仍会呈现；此设置仅影响当前播放器，不修改录制内容。效果不合适时选回“关闭”。
- 播放器中显示的是录制快照和交互提示，不是可操作的原管理平台。演示中的虚拟机创建、删除等动作不会被再次提交到原平台。

## 管理本机演示

侧边栏“我的演示”为每条记录提供“编辑热点”“播放”“删除”。编辑热点不会重新录制网页；如果原始操作路径需要变化，应重新录制一条演示。

“删除”会先要求确认。确认后，该演示的录制事件、热点和本地资源文件会从素材库中永久移除，工具内无法恢复。正在录制的演示不能删除，须先结束录制。删除前请确认选中的是正确记录，并按需要先备份素材库。

素材库保存在你选择的本机目录。换机或重装前，应备份**整个素材库目录**，不要只复制某个 `events` 或 `assets` 子目录；恢复后在工具中重新选择并授权该目录。工具目前没有内置的云端同步或一键分享功能。

## 图片、图标与离线回放

录制时，工具会尝试保存已发现且受支持的同源静态资源，包括图片、外部 SVG、CSS 背景图和部分图标字体。“已保存 X / 已发现 Y 项离线资源”只统计工具发现的候选资源，不等于整个网站可以离线运行。资源无法读取、受鉴权限制、超出上限或格式不受支持时，会显示在“未保存资源”列表中；请根据实际演示画面判断是否影响使用。

如果录制时连接 VPN、断开 VPN 后出现图片或图标缺失，先查看“未保存资源”和播放器资源警告。连接 VPN 时，部分未保存资源可能仍从原站点加载；因此，准备脱离 VPN 展示的演示必须在断开 VPN 后完整播放验证。网页脚本、视频、音频、Canvas 和跨域 iframe 内部内容不保证被保存；单项资源上限为 10 MB，每条演示的去重资源上限为 200 MB。

## 常见问题

| 现象 | 处理建议 |
| --- | --- |
| “无法开始录制：请先打开要录制的网页” | 在侧边栏填写 HTTP/HTTPS 地址，点击“打开目标页面”，确认页面加载后再开始录制。 |
| 提示未获得网站访问权限 | 在浏览器权限弹窗中允许目标网站访问，然后重试“开始录制”。 |
| 提示素材库无权限、编辑器或播放器无法读取演示 | 返回侧边栏点击“授权并刷新素材库”；必要时重新选择原素材库。不要误选空目录。 |
| 结束录制时提示保存中断 | 保持素材库所在磁盘可用，等待写入恢复后按提示重试保存；确认完成前不要开始新录制。 |
| “未检测到点击操作”或无法添加热点 | 确认录制过程中确实在目标页面执行了点击；如缺少关键点击，重新录制该操作路径。 |
| 点击热点没有进入下一步 | 仅点击播放器画面中的高亮区域；若热点位置不准，在“编辑热点”中移除并重新选择对应点击。 |
| 回放图片、字体或图标缺失 | 查看“未保存资源”和播放器警告；连接 VPN 对比回放效果，并记录失败项供排查。不要把“已发现资源均已保存”理解为完整离线保证。 |
| 演示显示“录制未完成” | 打开并检查可用片段；如关键末尾缺失，重新录制。 |

## 使用边界与反馈

本工具适合把预设网页流程制作成交互式演示，不适合代替原平台执行真实操作，也不保证跨域内容或整个网站的离线可用性。演示素材只保存在使用者本机，但可能包含敏感页面内容，请按公司要求保管、备份和删除。

反馈问题时，请提供工具版本、Windows 与浏览器版本、录制或播放时的 VPN 状态、操作步骤、预期与实际结果，以及脱敏后的截图和资源失败数量。**不要发送原始素材库、完整 HAR、Cookie、令牌或未脱敏的内网页面截图。**
