# SMTX Demo Builder 内测试点指南

适用对象：使用 Windows、Microsoft Edge 或 Google Chrome 的一线售前同事。当前试点版本为 **v0.1.0**。本工具用于录制网页操作、设置交互热点，并按预设步骤回放演示；无需安装 Node.js 或获取项目源码。

## 试点前准备

- 使用经批准的演示环境和测试数据。录制文件可能包含页面文本、图片等内容，请勿录入客户真实数据、账号密码或其他敏感信息。
- 录制内网网站前连接 VPN，并确认目标页面可正常打开。回放时是否需要 VPN 取决于资源保存情况，不能以“录制成功”判断演示一定可以完全离线使用。
- 准备两个不同的本机目录：一个放解压后的**扩展程序文件**，另一个作为工具内选择的**演示素材库**。素材库请放在公司允许使用的非同步本地目录，不要放在临时目录或自动同步网盘。
- 如公司策略禁止浏览器开发者模式，请联系试点负责人或 IT；不要绕过设备管理策略。

## 获取并安装 v0.1.0

1. 从[私有仓库发布页](https://github.com/zkx2021/smtx-demo-builder/releases/tag/v0.1.0)或试点负责人指定的内部渠道获取 `SMTX-Demo-Builder-v0.1.0.zip` 和同名 `.sha256` 文件。GitHub 发布页需要仓库读取权限。**不要下载页面上的 “Source code” 压缩包**，它不是可安装的扩展包。
2. 可在 PowerShell 中运行以下命令，核对输出的 SHA-256 与 `.sha256` 文件开头的 64 位字符一致；若不一致，停止安装并联系试点负责人。

   ```powershell
   (Get-FileHash -LiteralPath .\SMTX-Demo-Builder-v0.1.0.zip -Algorithm SHA256).Hash
   ```

3. 将 ZIP 解压到固定的本机目录。打开解压目录，确认其中直接有 `manifest.json`；安装时选择这一层目录，不要选 ZIP 文件或它的上级目录。
4. 在 Edge 输入 `edge://extensions`，或在 Chrome 输入 `chrome://extensions`。开启“开发者模式”，点击“加载已解压的扩展程序”，选择上一步的目录。浏览器安装方法见 [Edge 官方说明](https://learn.microsoft.com/en-us/microsoft-edge/extensions/getting-started/extension-sideloading)与 [Chrome 官方说明](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world)。
5. 点击浏览器工具栏中的 SMTX Demo Builder，打开侧边栏；在“本地素材库”中点击“选择素材库目录”，选中准备好的演示素材库并授权。

## 完成一次试点演示

1. 保持 VPN 连接。在侧边栏填写“目标页面地址”，点击“打开目标页面”。确认页面已打开并可操作后，填写“演示名称”，点击“开始录制”；按浏览器提示授予该网站的访问权限。录制期间保持侧边栏打开。
2. 在目标页面完成一条预设操作路径，返回侧边栏点击“结束录制并保存”。在“我的演示”中确认记录显示为“可播放”，并查看离线资源的已保存数量及“未保存资源”提示。
3. 点击“编辑热点”，从右侧“点击操作”中选中需要售前观众参与的点击，填写“热点名称”，点击“添加交互热点”。至少设置一个热点。
4. 点击“播放演示”。播放器在交互步骤暂停时，应点击画面中的高亮热点继续。可试用“全屏”；“播放加速”默认关闭，如需比较效果可选择 1、2、3 秒，然后切回“关闭”。回放**不会**在原管理平台执行操作。
5. 关闭并重新打开播放器，确认演示仍可读取。若需要评估脱离 VPN 的展示效果，可在录制完成后断开 VPN 再播放一次，记录缺失的图片、字体或图标；不要把部分资源已保存理解为完整离线保证。
6. 仅对不再需要的**测试演示**试用“删除”。删除确认后会永久移除该条演示及其本地资源，工具内无法恢复；不要删除正式素材。

## 更新与回退

更新前先结束录制，备份当前扩展目录；如需回退，也先备份演示素材库。把新版 ZIP 解压后的文件放回**同一个扩展目录**，再在浏览器扩展管理页点击“重新加载”，重新打开工具。回退时用备份的旧版扩展文件恢复该目录，再点击“重新加载”。演示素材库与扩展目录相互独立；如果改从另一目录重新安装，可能需要重新选择并授权原素材库。旧版工具不一定能读取新版创建的演示，请保留素材库备份。

本指南只适用于当前少量同事通过开发者模式加载扩展的试点，不代表浏览器商店发布或企业集中部署方案。
