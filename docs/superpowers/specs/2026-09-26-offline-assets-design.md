# SMTX Demo Builder：离线静态资源设计

日期：2026-09-26

## 目标与验收

售前在连接 VPN 时录制内网管理平台，之后即使断开 VPN，也能在本机播放演示中已捕获的图片和图标。资源只保存在该售前选择的本地素材库，不上传，也不要求修改被录制的平台。无法发现或无法读取的资源不得被宣称为已离线保存；用户应在结束录制后及播放前看到明确的覆盖状态和失败原因。

首版验收使用本地测试站点录制 `<img>`、`srcset`、CSS 背景图、外部 SVG 图片和 `@font-face` 图标字体，关闭测试站点后仍应显示已捕获资源，热点暂停与播放加速行为不变。真实内网平台需要用户在 VPN 环境下做最终验收；本地测试不能代替该环境。

## 方案选择

采用独立的本地资源包。rrweb 的 `inlineImages` 只处理部分图片情形，默认关闭且在 2.x 中标记为弃用；将大量图片直接放进事件 JSON 还会放大当前一次性读取、解析全部录制事件的成本。浏览器调试接口可以观察实际网络响应，但要求更强的 `debugger` 权限；本版不采用。

资源包只尝试在录制页面中读取与页面同源的 HTTP(S) 资源，以及仍有效的同源 `blob:` 资源。`data:` URL 与内联 SVG 已包含内容，不再另存。跨域资源、受特殊请求头保护的资源，以及无法读取的资源记为未捕获，不自动索取额外域名权限，也不静默回退为“离线完整”。

## 资源发现与捕获

在现有录制内容脚本中增加独立的资源收集器。它从 rrweb 完整快照和后续变更中提取资源引用，并使用浏览器资源性能条目补充动态加载的图片、CSS 和字体地址；性能条目中的脚本、XHR 等非静态资源不进入候选集。首版识别 `img/src`、`picture/source/srcset`、SVG `image/use` 的外部引用、已记录的内联样式和样式表中的 CSS `url()`，包括背景图和 `@font-face` 字体。仅把这些明确的资源上下文当作候选，不能把普通链接或任意字符串当作下载地址。

收集器规范化 URL，按 URL 去重，并在页面仍可访问时以页面身份请求同源资源，携带正常会话凭据。只接受图片、SVG 图片和字体的预期 MIME/扩展名组合；HTML、脚本和其他响应不进入资源包。单个资源最多 10 MB；一个演示中实际存储的去重资源总量最多 200 MB。超限、HTTP 失败、类型不符、跨域、读取超时等均产生带原因的失败记录。最多并发捕获 4 项，单项等待最多 10 秒，不阻塞 rrweb 事件产生；录制结束时最多等待捕获队列 30 秒，剩余项记为超时，然后结算覆盖状态。

Chrome 扩展消息使用 JSON 序列化，因此二进制资源经限量编码、分块传给仍打开的侧边栏，由侧边栏写入用户选定的目录；不把二进制塞进 rrweb 事件批次。每项成功资源在写入完成后才更新索引。资源写入失败不丢弃已有录制事件，但会标为离线资源不完整。

## 本地数据与兼容性

新录制使用格式版本 2，在 `demos/<id>/assets/` 下以 `SHA-256` 内容哈希加 MIME 对应扩展名保存独立文件，`demos/<id>/assets/index.json` 保存 URL、文件名、MIME、字节数及捕获结果的索引。内容相同的资源在一个演示内只存一份；200 MB 限额按实际去重后的字节计算。文件先写完、再登记成功索引，避免半写入文件被当作可用资源。

演示清单增加离线资源汇总：已发现数、成功数、失败数、去重后字节数与 `complete`/`partial` 状态。这里的 `complete` 只表示**已发现的受支持资源**全部捕获，不保证页面所有可见内容均已离线化；未发现候选时显示“未发现需保存的资源”。旧格式版本 1 不迁移、不修改；继续按原逻辑播放，并在界面显示“未保存离线资源”。已有录制无法在断开 VPN 后补回此前未保存的资源。

资源索引保留精确 URL 供回放匹配；界面展示失败清单时隐藏查询参数和凭据片段。录制页面原有的敏感内容及资源本体仍可能存入本地素材库，应沿用使用演示环境的提示。

## 回放映射与性能

编辑器和播放器加载格式版本 2 时，先读取资源索引，为已捕获文件建立本地 Blob URL，再在**回放用副本**中把相应的图片、`srcset`、SVG 引用和 CSS `url()` 替换为本地地址，不修改磁盘上的 rrweb 原始事件。替换仅发生于已识别的资源上下文；失败资源保留原始地址，以便连着 VPN 时仍可能显示，并同步显示离线不完整提示。页面关闭或更换演示时释放 Blob URL。

图片和字体独立于事件 JSON 保存，避免增加录制事件的解析体积。播放器在开始前优先准备首屏资源，在步骤播放期间预备下一步骤的资源；其余资源按需由浏览器从本地文件加载。捕获队列和预加载均有并发上限，不为了等待非关键资源而冻结热点交互。若首屏资源加载失败，仍可播放，但必须提示缺失。

## 失败提示与边界

录制结束时展示“已保存 X / 已发现 Y 项离线资源”和失败项清单；播放器展示“已发现资源均已保存”“离线资源不完整”“未发现需保存的资源”或“此旧演示未保存离线资源”。失败项列出资源类型、脱敏地址和原因。用户可以继续编辑或播放部分资源已保存的演示；不自动删除任何录制或资源文件。

首版不处理视频、音频、Canvas 绘制内容、跨域 iframe 内部、浏览器内部页面，也不保证无法被 rrweb 或资源观察器发现的动态资源。外部样式表若无法被 rrweb 内联且不能安全捕获，须计入已发现的缺失项；界面不得用“完整”暗示整个网站完全离线。特殊鉴权或跨域资源需未来单独设计权限与捕获策略。

## 验证

单元测试覆盖 URL 发现和规范化、`srcset`/CSS 引用改写、MIME 与大小限制、哈希去重、失败状态汇总、旧格式兼容。Edge 扩展端到端测试在本地站点录制常见图片与字体，停止站点以模拟断 VPN，验证播放器与编辑器使用本地资源、无源站请求、热点和播放加速仍正常；另测跨域/超限资源显示失败原因。性能检查记录素材库体积、演示打开耗时、步骤切换的最长帧间隔，并与未启用资源包的同一测试场景比较；若出现可感知停顿，应优化后再交付，不宣称“零卡顿”。真实 VPN 平台的最终可用性需由用户提供环境进行验收。
