# SMTX Demo Builder（样机）

SMTX Demo Builder 是适用于 Windows 平台 Chrome/Edge 的 Manifest V3 扩展。用户可录制网页操作、配置交互热点，并在独立标签页回放演示。录制数据仅写入用户指定的本地目录。

实际操作请阅读 [使用指南](docs/user-guide/README.md)；首次安装和小范围试用请阅读 [内测试点指南](docs/pilot/README.md)。下文为项目构建与技术说明。

## 构建与安装

要求 Node.js 20+、Chrome 116+ 或兼容的 Edge 版本。

```powershell
npm install
npm run typecheck
npm test
npm run package:extension
npm run smoke
```

在 `chrome://extensions` 或 `edge://extensions` 打开“开发者模式”，选择“加载已解压的扩展程序”，指向本项目的 `dist` 文件夹。扩展图标会出现在浏览器工具栏；点击后打开侧边栏。

## 内测包安装与更新

`npm run package:extension` 会先执行干净构建，再在 `output/releases/` 生成 `SMTX-Demo-Builder-v<版本号>.zip` 和同名 `.sha256` 校验文件。版本号必须同时与 `package.json`、`manifest.json` 一致。ZIP 解压后的根目录直接包含 `manifest.json`，可作为“加载已解压的扩展程序”的目标；不要使用 GitHub 自动生成的源码 ZIP。仓库的 GitHub Actions 会在推送到 `main`、提交 PR 或手动触发时执行类型检查、测试、构建和打包。内测同事应从成功的 `main` 分支运行或经确认的手动运行下载产物，也可以通过公司内部渠道获取 ZIP；不要把演示素材库一起分发。

首次安装：将 ZIP 解压到固定的本地目录，在 `edge://extensions` 或 `chrome://extensions` 启用开发者模式，选择“加载已解压的扩展程序”，选中包含 `manifest.json` 的目录。安装后在工具中选择自己的本地演示素材库。可用 `Get-FileHash .\SMTX-Demo-Builder-v0.1.0.zip -Algorithm SHA256` 核对同版本 `.sha256` 文件中的值。

更新：先结束正在进行的录制，备份旧版扩展目录，在原扩展目录替换为新版解压文件，然后在扩展管理页点击“重新加载”，并重新打开工具。回退：将备份的旧版文件恢复到同一扩展目录，再点击“重新加载”。扩展文件与演示素材库是两个独立目录；更新或回退扩展文件不会删除素材。若改为从另一目录重新安装，可能需要在工具中重新选择原素材库。回退前仍应备份素材库，因为旧版不一定支持新版创建的演示格式。

## 试录

1. 在录制面板中选择一个本地目录作为演示素材库。
2. 打开要录制的 HTTP/HTTPS 页面，填写演示名称，选择“开始录制”，并授予目标网站的访问权限。
3. 完成页面操作后，选择“结束录制并保存”。
4. 在新标签页的热点编辑器中，选择点击操作并选择“添加交互热点”。
5. 选择“播放演示”；播放器将在交互步骤前暂停，点击高亮区域后继续。播放器右上角提供“播放加速”和全屏控制。

“我的演示”中每条记录提供“编辑热点”“播放”“导出”“删除”。完成录制并添加至少一个热点后，点击“导出”，选择保存位置，得到可上传至 DemoCenter 的单演示 `.smtxdemo` 文件。导出不会修改本机素材库；未保存的离线资源会在导出结果中提示。`.smtxdemo` 与安装扩展用的 ZIP 是不同文件，不能用来安装扩展。删除需要确认，确认后会永久移除该演示目录中的录制事件、热点和离线资源文件，无法从工具中恢复；正在录制的演示须先结束录制。

“播放加速”默认关闭，选项为关闭、1 秒、2 秒、3 秒。启用后，录制中相邻点击之间超过所选时长的区间约按所选时长播放，较短区间保持原速；鼠标轨迹和页面变化继续回放。切换选项立即生效，选择“关闭”即可恢复录制原速。此选项只影响当前播放器，不修改演示素材或热点。修改扩展代码后，请在浏览器的扩展管理页点击此扩展的“重新加载”，再重新打开播放器查看更新。

可用 `npm run fixture` 启动本地测试页，然后打开 `http://127.0.0.1:4173/fixture.html` 测试“新建虚拟机 → 确认创建”。

`npm run smoke` 会在临时 Edge 配置中自动完成录制、页面刷新、选择热点、导出和播放，并将播放器截图写到 `output/playwright/player.png`。验证与网站的兼容性时，先启动 DemoCenter，再运行 `$env:DEMO_CENTER_URL='http://127.0.0.1:8080'; npm run smoke:democenter`。此命令要求设置网站地址，会上传真实 Edge 导出的包、打开网站播放器点击热点，并在结束后删除联调记录。自动测试用浏览器临时存储模拟目录选择；正式使用时仍由售前在系统目录选择器中选定本机目录。

## 素材位置与当前边界

目录结构为 `demos/<demo-id>/manifest.json`、`steps.json`、`events/<batch-id>.json`，以及新版演示的 `assets/index.json` 和以内容哈希命名的资源文件。目录句柄保存在扩展的 IndexedDB，录制事件与资源只写入所选本地目录，不上传到服务器。素材库可能保存网页文本、图片和字体等敏感内容，请使用无敏感数据的演示环境并妥善保管目录。

录制时扩展尝试保存已发现、与目标页面同源的 HTTP(S) 图片、外部 SVG、CSS 背景图和图标字体，以及仍有效的同源 `blob:` 资源。`data:` 图片与内联 SVG 无需另存。单项资源上限为 10 MB，每个演示实际存储的去重资源上限为 200 MB。HTML、脚本、视频、音频、Canvas 内容、跨域 iframe 内部资源和跨域资源不自动保存。SVG 可包含一个受限的静态类选择器样式块，并支持绘图属性、渐变停止点等有限的内联样式；脚本、动画、外部引用、其他样式语法、XML 字符引用及 CSS 转义仍会被拒绝。受特殊鉴权限制、无法读取、超限或不支持的资源会显示在失败清单，地址会隐藏查询参数和片段。

侧边栏、编辑器和播放器会显示“已保存 X / 已发现 Y 项离线资源”、失败原因及回放时发现的本地文件缺失或解码警告。部分资源失败时仍可编辑和播放；连着 VPN 时，失败项可能继续从原地址加载。“已发现资源均已保存”仅指已发现且受支持的静态资源，不表示整个网站离线可用。旧版演示没有保存离线资源，若要离线播放这些素材，须在 VPN 连接期间重新录制。

rrweb 可能把 CSS 中的 `url(#渐变ID)` 展开成“样式表目录 URL + 片段”。工具将这类目录型 CSS 片段视为页内引用，不再尝试下载；打开旧演示时也会在内存中修正回放内容与资源覆盖统计，不改写原有录制文件。若网站确实通过以 `/` 结尾的地址提供外部 SVG 资源，请单独验证其离线效果。

当前样机录制单个标签页及其主文档，侧边栏需要在录制期间保持打开。若写入失败，录制会暂停并在侧边栏提示。页面刷新后，同一标签页会重新启动录制；浏览器内部页面以及未被录制器发现的动态资源不在完整回放保证内。输入框值默认由 rrweb 遮蔽，但网页中的普通文本仍会出现在录制快照中。
